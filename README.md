# UI-CAF-AFCON-INSTORE-ACTIVATION
Developed an interactive Power BI dashboard analyzing the UI CAF AFCON Activation across four cities. It tracks consumer reach, sales volume, revenue, brand performance, and weekly sales trends, providing actionable insights into campaign effectiveness, target achievement, and geographical performance to support data-driven marketing decisions.
